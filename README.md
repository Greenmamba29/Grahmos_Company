# Grahmos_Company

This is the company-operations repo for GrahmOS and its Paperclip/Cursor Cloud setup.

## Repo scope

- Contains CEO agent instructions and company-level Paperclip documentation.
- Does not contain product application code or product monorepos such as `@grahmos/platform`.
- When an issue references a package or monorepo that is not present here, the next action is to route the work to the correct source repository before attempting implementation.
