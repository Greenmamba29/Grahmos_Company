# Grahmos_Company
This is the Company run main repo for Grahmos

## Operational helpers

- `scripts/update-paperclip-issue.sh`: update a Paperclip issue status and optional comment once `PAPERCLIP_API_KEY` or `PAPERCLIP_API_KEY_FILE` is available in the runtime.
- `skills/grahmmos-paperclip/SKILL.md`: company setup, auth troubleshooting, and Paperclip operating notes for GrahmOS agents.
